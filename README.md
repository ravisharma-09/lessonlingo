# LessonLingo

LessonLingo is a Python project for translating lesson content.

## Development

Create and activate a Python 3.11 virtual environment:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
```

Run the test suite:

```bash
python -m pytest
```

Tests use a fake translator and do not download model files.
