What it does

One English lecture in. Three things out.

SUBTITLES

Every language, every line

Subtitle files (.srt and .vtt) for each language you pick, or one video with all of them inside to switch in any player.

DUBBED VOICE

A voice that sounds like a person

Hindi and Kannada speech made locally with an open voice model. One video carries the original sound and every dubbed track.

FOR TEACHERS

Check before you share

Fix the English text before it is translated, keep words like photosynthesis untouched, and translate a whole course folder in one go.

How it works

Five steps, and you can go back at any one.

  1. AddText, video, audio or a subtitle file.
  2. LanguagesTick the ones you need. Hindi and Kannada can also be spoken.
  3. OptionsFast or best-quality model, and what you want back.
  4. Check textFix any mistake in the English before it is translated.
  5. ResultWatch it, switch audio and subtitles, download everything.
ffmpeg→Whisper→IndicTrans2→Voice (Parler-TTS or MMS)→.srt · .vtt · .mp4

Each model is freed before the next one loads, so a laptop with 8 GB of graphics memory is enough. Timestamps never change, so subtitles stay in step with the picture.

Specifications

What it needs, what it gives, how long it takes.

What it supports

InputText (.md, .txt), video (mp4, mkv, mov, webm), audio (mp3, wav, m4a), subtitle files (.srt, .vtt). Source language: English.
Translates intoHindi, Kannada, Tamil, Telugu, Malayalam, Bengali, Marathi, Gujarati, Punjabi, Odia.
Spoken voiceHindi and Kannada.
OutputSubtitle files, video with subtitles inside, video with subtitles and dubbed audio tracks, a class pack zip.
CoursesA folder per class; batch translate from the app or the command line.

Models (downloaded once)

Translation, fastIndicTrans2 200M, about 1.1 GB. Runs on any laptop.
Translation, bestIndicTrans2 1B, about 4.5 GB. Needs an NVIDIA GPU.
Speech to textWhisper (small) through faster-whisper, about 0.5 GB.
Voice, naturalIndic Parler-TTS, 3.75 GB. Sounds like a person. GPU recommended.
Voice, quickMeta MMS-TTS, about 145 MB per language. Robotic, much faster. Non-commercial licence.

Hardware

Tested onWindows laptop, RTX 4070-class GPU (8 GB), 16 GB RAM, Python 3.11.
Any laptop (CPU)Subtitles, text lessons and the quick voice should work, only slower. We have not measured CPU-only speed yet.
NVIDIA GPUNeeded for the best-quality model, and recommended for the natural voice.
SoftwarePython 3.11, ffmpeg, git (for the voice add-on), a free Hugging Face account for setup.

How long it takes

ListeningAbout 15 seconds for each minute of video.
Subtitles, start to endAbout 20 seconds for each minute of video. We measured 12 seconds for a 61-second lecture on the test laptop.
Quick voiceAbout 1 minute for each minute of video (estimate).
Natural voiceAbout 8 to 9 minutes for each minute of video. Worth it for the sound, and you can cancel any time.
Text lessonA few seconds.

Measured on our test laptop. Your numbers will differ with your hardware.

Setup guide

Install once. After that, no internet.

The first install, the model download and the Hugging Face login need internet. Translating afterwards does not.

1

Install the basics

Python 3.11, git and ffmpeg. In PowerShell:

winget install Python.Python.3.11 winget install Git.Git winget install ffmpeg
2

Get the code

Clone the repository and create a Python environment.

git clone https://github.com/ravisharma-09/lessonlingo.git Set-Location lessonlingo py -3.11 -m venv .venv Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass .\.venv\Scripts\Activate.ps1 python -m pip install --upgrade pip
3

Install PyTorch and the app

For an NVIDIA GPU use the CUDA build. On a CPU-only laptop, install plain torch instead.

python -m pip install torch --index-url https://download.pytorch.org/whl/cu124 python -m pip install -r requirements.txt
4

Log in and accept the model terms

Make a free Hugging Face account, accept the terms on both IndicTrans2 model pages, then log in.

hf auth login

IndicTrans2 200M · IndicTrans2 1B · Indic Parler-TTS (for the natural voice)

5

Download the models

One time, while online. Add the voice add-on if you want the natural Hindi and Kannada voice.

python -m pip install -r requirements-voice.txt lessonlingo setup --voices hin_Deva kan_Knda --voice-engine parler

Skip the first line and add nothing after setup for subtitles only. Use --voice-engine mms for the small robotic voice.

6

Run it

Turn Wi-Fi off if you like. Open the address it prints, usually http://127.0.0.1:7860.

lessonlingo app --warm light --offline
1

Install the basics

Python 3.11, git and ffmpeg (macOS with Homebrew).

brew install python@3.11 git ffmpeg
2

Get the code and install

git clone https://github.com/ravisharma-09/lessonlingo.git cd lessonlingo python3.11 -m venv .venv source .venv/bin/activate python -m pip install --upgrade pip python -m pip install torch python -m pip install -r requirements.txt
3

Log in, download, run

Same Hugging Face steps as Windows, then:

hf auth login lessonlingo setup lessonlingo app --warm light --offline

We built and tested the real models on Windows with an NVIDIA GPU. macOS and Linux have only been run with test stand-ins so far.

Or use the command line

Everything in the app also works without it.

lessonlingo languages lessonlingo video .\lecture.mp4 --to kan_Knda hin_Deva --dub --offline --out .\outputs lessonlingo course new "Science 8" --to kan_Knda hin_Deva lessonlingo course translate "Science 8" --offline

Honest limits

What it cannot do yet.

Know before you use it

  • Translation can be wrong. That is why there is a Check step, and why a fluent speaker should review important material.
  • Speech recognition can miss accents and technical words. Doubtful words are flagged.
  • The dubbed voice is one voice per language, with no emotion and no lip-sync.
  • Voice is Hindi and Kannada only. Other languages get subtitles.
  • It handles one job at a time and has no login, so keep it on your own laptop.

Not measured yet

  • Lectures longer than a few minutes. We tested a 61-second lecture.
  • Speed on a laptop with no GPU.
  • A fluent-speaker rating of translation quality (a pilot sheet is in the repo).
  • macOS and Linux with the real models.

Questions

Why is there no hosted version to try?

The models need a GPU and several gigabytes of weights, and the whole point is that nothing leaves your computer. So LessonLingo is a tool you run yourself. This page is the guide, and the proof video shows it working.

Does it really work offline?

Yes, after setup. The install, the model download and the Hugging Face login need internet once. After that, translating, listening and dubbing need none. Start the app with --offline to be sure.

Can I use it on a basic laptop?

Subtitles and text lessons should run on any laptop with the fast model, only slower. The best-quality model needs an NVIDIA GPU, and the natural voice is much happier with one. The quick voice is a lighter alternative.

Is it free for schools?

The code is MIT. Most models are permissive, but the quick MMS voice is non-commercial, so check each model's licence before using it for anything commercial.
