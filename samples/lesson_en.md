# Variables in Python

A variable gives a name to a value. Variables help us reuse information in a
program.

## Example

```python
student_count = 24
print(student_count)
```

The code block must remain unchanged when the explanation is translated.

> Try changing the value and running the program again.

| Name | Meaning |
| --- | --- |
| `student_count` | Number of students in the class. |
