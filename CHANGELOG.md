# Changelog

## 0.1.0 (Devf8rge finals build)

- Translate Markdown and text lessons into 10 Indian languages with IndicTrans2.
- Translate English lecture videos: ffmpeg, faster-whisper, then IndicTrans2, written as
  `.srt` and `.vtt`, with `--embed` for selectable subtitle tracks in an mp4.
- Keep chosen words in English, review and edit translations, translate whole folders.
- Gradio web UI (`lessonlingo app`) and CLI. Set up once, then no internet needed.
